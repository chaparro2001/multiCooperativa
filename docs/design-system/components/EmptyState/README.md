# EmptyState

A centred, calm message for an empty list: a 48 px `secondary` module icon and the per-screen copy in `bodyLarge` `muted`.

- Use the module's own icon (`bullhorn-outline`, `hand-back-left-outline`, `file-document-outline`…) — no illustrations or sector imagery.
- Copy comes from the brief: "Todavía no hay comunicados.", "No hay asambleas convocadas.", "No hay facturas.", "Ningún título coincide.", "No se ha encontrado nada parecido.".
- A manager may get the create action underneath (e.g. "Nuevo comunicado"); members get none.

The consumer provides: `message`, optional `icon`, `title`, `action`.
