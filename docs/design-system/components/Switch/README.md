# Switch

MD3 switch on the right of a labelled row; the label sits left with an optional help line in `muted`.

- Used for "Desbloqueo con biometría", the three invoicing reminders, "Se somete a votación" and "Es socio".
- When a reminder is off, the help line explains what that means instead of leaving the row blank.
- On: `primary` track, `on-primary` thumb. Off: `surface-variant` track with `muted` outline — the thumb size changes too, so state is not colour alone.

The consumer provides: `label`, `value`, `onChange`, optional `help`.
