# SourceCard

One citation under an assistant answer: clear but secondary to it.

- Grouped under a `secondary` "Fuentes" heading with `text-box-search-outline`, indented `space-2` from the bubble.
- Outlined (`border`, `radius-sm`), numbered disc in `primary-container`, title in `labelLarge` ("Título · pág. N"), 2-line excerpt in `muted`, and a trailing icon for the kind of source: `file-document-outline` (document), `receipt-text-outline` (invoice), `package-variant-closed` (delivery note), `office-building-outline` / `store-outline` (third party), `hand-back-left-outline` (assembly), `bullhorn-outline` (announcement).
- Tapping opens the document at that page, or the entity's detail.

The consumer provides: `title`, `excerpt`, optional `n`, `icon`, `onPress`.
