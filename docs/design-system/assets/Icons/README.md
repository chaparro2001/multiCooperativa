# Icons

The MaterialCommunityIcons glyphs this system uses, copied unchanged from `@mdi/svg` 7.4.47 (Pictogrammers Free License). Each file is a 24×24 single-path SVG with no fill set, so it renders black in an `<img>`; in the app it inherits the colour of its container (`primary`, `secondary`, `muted`, `danger`, `warning`). The full set is allowed in the app; these are the names the brief and the components reference.
